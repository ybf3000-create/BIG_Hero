## 1. 战斗宏观流程

```
触发战斗（踩到🗡战斗格 / ⚔精英格 / 🏆挑战格 / Boss格）
  ↓
Step A — 战斗初始化
  ├─ 生成怪物（等级/属性/外观/被动）
  ├─ 初始化战斗状态（HP全满、技能CD=0、计时器归零）
  └─ 进入战斗场景
  ↓
Step B — 战斗主循环（全自动）
  ├─ CD 倒计时（真实时间流逝）
  ├─ 单位 CD 归零 → 执行行动
  ├─ 行动后重置该单位 CD
  └─ 每次行动后检查胜负条件
  ↓
Step C — 战斗结束
  ├─ 判定胜负
  ├─ 结算奖励（EXP/金币/掉落）
  └─ 回到地图，立即掷骰继续走圈
```

| 特性 | 说明 |
|------|------|
| 操作方式 | 全自动，无需玩家操作 |
| 时间流速 | 真实时间（1秒 = 现实 1 秒） |
| 中途操作 | 仅"撤退"按钮（在线时） |
| 地图影响 | 战斗期间地图走圈暂停，战斗结束立即恢复 |

## 2. 参战单位

每场战斗由 **玩家角色** vs **敌方怪物阵容** 组成。

### 2.1 玩家战斗属性（带入战斗的值）

战斗开始时，从角色当前属性快照以下值，战斗内不变：

| 属性     | 来源                 | 说明                      |
| ------ | ------------------ | ----------------------- |
| 总HP    | 角色属性案 §6.4         | 战斗内 HP 上限，可被护盾临时增加      |
| 当前HP   | = 总HP（开局满血）        | 挑战格连战时保留上一波剩余 HP        |
| 总攻击力   | 角色属性案 §6.1         | 普攻 + 技能的伤害基数            |
| 总防御力   | 角色属性案 §6.2         | 代入装备减伤公式                |
| 自由防御减伤 | 自由点 × 1.5%（上限 50%） | 独立乘算减伤                  |
| 出手CD   | 角色属性案 §6.5         | `3.0 × (1 - 总速度点×0.01)` |
| 命中率    | 装备词条               | 对抗目标闪避                  |
| 暴击率    | 装备 + 宝石            | 普攻和技能均可暴击 |
| 暴击伤害倍率 | 基础 150% + 装备 + 宝石  |                         |
| 闪避率    | 装备 + 宝石 + 套装       |                         |
| 格挡率    | 装备 + 头盔            |                         |
| 技能列表   | 已装备的 2~6 个技能       | 每个技能独立 CD               |
| 吸血%    | 装备 + 套装            | 伤害 × 吸血% → 治疗自身         |
| 回血/步   | 装备                 | 战斗中不触发（仅走格时）            |

## 3. 行动队列与 CD 系统

### 3.1 CD 队列机制

```
所有参战单位各有独立的"出手CD 计时器"。

出手CD 计时器 = 实时倒计时，按真实时间每秒递减。
计时器归零 → 该单位进入"行动队列"。
行动队列按 CD 归零先后顺序排队执行。

执行完毕后 → 该单位出手CD 重置为完整值，重新开始倒计时。
```

### 3.2 出手CD 计算公式

```
单位出手CD = 基础出手CD × (1 - 速度修正)

基础出手CD：
  玩家角色：  3.0 秒
  普通小怪：  3.5 秒
  精英怪：    2.8 秒
  Boss：      2.5 秒

速度修正（仅玩家有）：
  = min(总速度点 × 0.01, 0.50)    ← 上限 -50%
  总速度点 = 自由速度点 + 装备速度点
  怪物速度修正 = 0
```

| 单位 | 基础CD | 最快CD（速度50点） |
|------|--------|-------------------|
| 玩家 | 3.0s | 1.5s |
| 普通怪 | 3.5s | 3.5s（不变）|
| 精英怪 | 2.8s | 2.8s |
| Boss | 2.5s | 2.5s |

### 3.3 单次行动流程

```
[单位出手CD归零]

Step 1 — 技能选择
  检查所有已装备并 CD 已归零的技能 → 按优先级选 1 个（见 §6）
  若无可用的技能 → 执行普攻（见 §5）

Step 2 — 执行动作
  选定技能 → 进入攻击判定流程（见 §4）
  普攻 → 直接进入伤害计算

Step 3 — CD 重置
  该单位出手CD = 基础出手CD × (1 - 速度修正)
  该单位使用的技能进入冷却倒计时（= 技能基础CD × (1 - 装备CDR%)）

Step 4 — 胜负检查
  检查敌方是否全灭 → 胜利
  检查玩家是否阵亡 → 失败
  检查回合上限（50 回合）→ 平局
  否则 → 继续战斗循环
```

### 3.4 同时归零处理

```
若多个单位的出手CD在同一帧归零：
  按以下优先级排序：
    1. 速度点高者优先
    2. 速度相同时 → 玩家优先
    3. 同为单位类型 → 随机排序
```

## 4. 攻击判定流程（修正版：三步独立判定）

> ⚠ 本节修正了原 GDD §3.10.1 的"圆桌一次ROLL"方案。
> 理由：暴击是攻击方参数，闪避/格挡是防御方参数，不应混在同一桌互斥。

### 4.1 判定总流程

```
每个攻击动作（普攻或技能）经历以下三步：

Step 1 — 命中判定（攻击方 vs 防御方闪避）
Step 2 — 暴击判定（仅技能，攻击方独立掷骰）
Step 3 — 格挡判定（防御方独立掷骰）
```

### 4.2 Step 1：命中判定

```
实际闪避率 = max(0, 防御方闪避率 - 攻击方命中率)

掷骰 [0, 100)：
  骰子 < 实际闪避率 → MISS（本攻击结束，伤害 = 0，无后续判定）
  骰子 ≥ 实际闪避率 → 命中，进入 Step 2

特殊情况：
  怪物命中率 = 100% → 怪物攻击玩家必定不 MISS
  怪物闪避率 = 0% → 玩家攻击怪物必定命中（先忽略命中属性）
```

### 4.3 Step 2：暴击判定

```
对该次攻击（普攻或技能）进行暴击判定：

掷骰 [0, 100)：
  骰子 < 攻击方暴击率 → 暴击标记 = true
  骰子 ≥ 攻击方暴击率 → 暴击标记 = false

普攻和技能一视同仁，均正常进行暴击判定。
```

### 4.4 Step 3：格挡判定

```
若攻击命中 → 防御方独立掷骰 [0, 100)：
  骰子 < 防御方格挡率 → 格挡标记 = true
  骰子 ≥ 防御方格挡率 → 格挡标记 = false

怪物格挡率 = 0%（当前版本，Boss 可能有特殊机制）
```

### 4.5 判定结果组合

| 命中 | 暴击 | 格挡 | 结果 | 伤害倍率 |
|------|------|------|------|---------|
| ❌ MISS | — | — | 无伤害 | 0 |
| ✅ 命中 | ❌ | ❌ | 普通命中 | ×1.0 |
| ✅ 命中 | ✅ | ❌ | 暴击 | ×暴击伤害倍率 |
| ✅ 命中 | ❌ | ✅ | 格挡 | ×0.5 |
| ✅ 命中 | ✅ | ✅ | 暴击且格挡 | ×暴击伤害倍率 × 0.5 |

> 暴击和格挡不互斥——可以同时触发（暴击的伤害被格挡减半），
> 这比原"圆桌互斥"更符合攻防独立的直觉。

### 4.6 AOE 与多目标判定

```
AOE 技能（敌方全体/前排全体/后排全体）攻击多个目标时，
对每个目标独立执行完整的 §4.1 三步判定流程。

即：
  AOE 技能打 3 个目标 → 每个目标各自走一遍：
    Step 1（命中 vs 该目标的闪避率）
    Step 2（暴击，攻击方独立掷骰 × 每个目标各掷一次）
    Step 3（格挡，该目标独立掷骰）

结果：可能命中 2 个、MISS 1 个；暴击 1 个、普通命中 2 个；各目标独立。
    不会出现"全暴或全不暴"的情况。

反向情况（规则2）：
  - 所有目标都 MISS → 技能完全落空，视觉效果显示全部 MISS
  - AOE 仅 1 个目标存活 → 等同于单体技能，正常三步判定
  - AOE 无存活目标（全灭）→ 技能不执行

设计意图：每目标独立判定让 AOE 有"散弹枪"的感觉——
  不是整齐划一的全体暴击/不暴击，而是每个目标有自己的命运。
  这也让"敌方格挡率"在 AOE 面前仍有防范价值。
```

## 5. 普攻规则

### 5.1 触发条件

```
单位行动时，若所有已装备技能的 CD 均未归零 → 执行普攻。

普攻特性：
  - 无 CD，始终可用（是兜底动作）
  - 不暴击（暴击仅限技能）
  - 不触发任何特殊效果（冰冻/燃烧/Dot 等）
  - 不消耗任何资源
```

### 5.2 普攻目标选择（基于站位）

> 完整站位规则见 [[怪物系统细化案【定案】]] §3。
> 站位图示：
> ```
>   玩家侧              敌人侧
>   ┌────┐   ┌────┬────┬────┐   ┌────┬────┬────┐
>   │ 👤 │ ←→│ 前1│ 前2│ 前3│   │ 后1│ 后2│ 后3│
>   └────┘   └────┴────┴────┘   └────┴────┴────┘
>              ↑前排（近战位）      ↑后排（远程位）
> ```

```
普攻按位序锁定目标：

Step 1 — 检查前排：
  若前排有存活怪物 → 锁定前排最左侧存活位置
    顺序：前1 → 前2 → 前3
    前排死亡后同排右侧自动左移补位（前2→前1，前3→前2）

Step 2 — 前排全灭 → 检查后排：
  锁定后排最左侧存活位置
    顺序：后1 → 后2 → 后3

Step 3 — 锁定规则：
  普攻不跨排：前排存活时不打后排
  目标锁定后持续攻击，直到该目标死亡 → 重新走 Step 1

Step 4 — Boss 战特殊：
  Boss 始终在前1位置，优先被锁定
  若 Boss 召唤小怪到后/前排其他位置，不改变普攻锁定优先级
```

### 5.3 普攻伤害（进入 §7 伤害管道）

```
普攻原始伤害 = 总攻击力 × 100%
→ 进入伤害计算管道（见 §7）
```

## 6. 技能释放规则

### 6.1 技能可用判定

```
每次行动时，扫描所有已装备技能：
  若 技能当前CD ≤ 0 → 该技能可用
  若 全部技能CD > 0 → 无可用技能，执行普攻
```

### 6.2 技能优先级

> 技能装备规则、优先级设定、完整技能列表 → 详见 [[技能系统细化案【定案】]]

```
当单位行动时，扫描所有已装备技能：

Step 1 — 筛选可用技能（CD ≤ 0）
Step 2 — 若有多个可用技能：
  → 按玩家设定的优先级等级排序（3 > 2 > 1，默认均为 1）
  → 同优先级内 → 按技能槽从左到右的顺序释放
Step 3 — 若全部技能 CD 均未归零 → 执行普攻

例：
  技能槽 [护盾:3] [毒刃:2] [重击:2] [治疗波:1] [连击:1] [烈焰灼烧:1]
  CD 归零的技能：重击(2) + 连击(1) + 烈焰灼烧(1)
  → 最高优先级 = 2 → 重击优先释放
  → 若只有连击(1) + 烈焰灼烧(1) → 从左到右，连击先释放
```

### 6.3 技能目标选择

> 完整目标选择规则（含站位逻辑、控制状态处理）→ 详见 [[技能系统细化案【定案】]] §3
>
> 战斗引擎仅执行：技能系统返回目标单位ID → 战斗引擎对该目标执行伤害/治疗/控制。

```
技能目标由技能系统根据"目标标签"和当前战场站位计算得出：

  输入：技能目标标签（如"前排位序"、"全场最低HP"、"敌方全体AOE"）
  处理：技能系统查询当前战场存活单位列表，按标签规则筛选目标
  输出：目标单位ID列表（1个或多个）

  战斗引擎接收目标列表 → 对每个目标执行 §4 判定流程 → §7 伤害管道
```

### 6.4 技能 CD 计算

```
技能释放后 → 该技能进入冷却：

实际技能CD = 技能基础CD × (1 - min(装备冷却缩减%, 0.50))

冷却缩减来自装备词条（+2%~+10%），多个词条加算，上限 50%。

例：技能 CD 8s，装备 CDR 15%
  → 实际 CD = 8 × (1 - 0.15) = 6.8 秒
```

## 7. 伤害计算全流程

一次攻击从原始伤害到最终扣血的完整管道：

```
Step 1 — 计算原始伤害
  原始伤害 = 总攻击力 × 技能倍率（普攻=100%）

Step 2 — 装备减伤（防御方）
  减伤系数 = max(0.05, 1 - 防御方防御力 / (防御方防御力 + 85 × 攻击方等级 + 400))
  伤害 = 原始伤害 × 减伤系数

  → 保底 5%：防御再高也不会完全免疫伤害

Step 3 — 自由防御减伤（仅玩家有）
  伤害 = 伤害 × (1 - min(自由防御点 × 0.015, 0.50))

Step 4 — 暴击/格挡修正（来自 §4 判定结果）
  暴击 → 伤害 × 暴击伤害倍率
  格挡 → 伤害 × 0.5
  两者同时 → 伤害 × 暴击伤害倍率 × 0.5

Step 5 — 其他修正（buff/debuff/神祇/套装/精英被动等）
  战神增益(+50%) → 伤害 × 1.5
  衰神减益(-50%) → 伤害 × 0.5
  技能大赛(+30%) → 伤害 × 1.3
  等等...（全部乘算叠加）

Step 6 — 吸血结算
  若攻击方有吸血% → 攻击方回复 HP += 最终伤害 × 吸血%

Step 7 — 护盾吸收（防御方）
  若防御方有护盾 → 护盾值优先吸收伤害
    护盾值 ≥ 伤害 → 伤害全部由护盾吸收，防御方HP不变，护盾值 -= 伤害
    护盾值 < 伤害 → 护盾被击破（归零），剩余伤害继续扣除HP
  无护盾 → 跳过此步

Step 8 — 最终扣血
  防御方当前HP -= 剩余伤害（经护盾吸收后）
  若防御方HP ≤ 0 → 该单位死亡
```

### 7.1 Dot 伤害规则

```
Dot（持续伤害）来源：毒刃、烈焰灼烧、撕裂等技能

Dot 实例模型：
  每个技能施加的 Dot 是独立实例，用 dot-id 区分。
  dot-id = 技能ID + 施加序号

  - 不同技能 → 不同 dot-id → 独立实例，各自跳伤害，互不影响
  - 同一技能再次施加 → 由技能的 Dot叠加模式 决定：
    模式A（刷新，默认）：刷新持续时间（不创建新实例）
    模式B（叠加）：创建新实例（与旧实例共存，各自独立计时）
  - 详见 [[技能系统细化案【定案】]] §6.7

Dot 触发规则：
  Dot 持续时间 T 秒内，受影响的单位**每次出手行动**时受到 Dot 伤害。
  出手越频繁（出手CD越短）→ 行动次数越多 → 受到 Dot 总伤害越高。
  
  例：Dot 持续 8 秒，攻击力×30%/次
    出手CD 3.0s（无速度）→ 8秒内行动 2 次（t=3s, 6s）→ 总Dot = 2 × 攻击力×30%
    出手CD 1.5s（速度封顶 50%）→ 8秒内行动 5 次（t=1.5/3/4.5/6/7.5s）→ 总Dot = 5 × 攻击力×30%
    速度流角色受到 Dot 总伤害 = 无速度角色的 2.5 倍

  首次施加 Dot 时是否立即跳伤害？
    → 否。施加时机不算"行动"，从施加后的第 1 次出手行动开始跳伤害。
    → 例：毒刃（8秒Dot）+ 目标出手CD 3.0s
       施加时(t=0)→不跳；第一次行动(t=3s)→跳；第二次行动(t=6s)→跳
       → 该目标在8秒内跳了 2 次，总Dot = 1 × 攻击力×30%

每跳伤害 = 攻击力 × Dot倍率（不受防御/暴击/格挡影响）

实例上限：同一目标最多同时存在 10 个 Dot 实例（不区分类型和 dot-id）
  超出时 → 最早施加的实例被移除（先进先出）

Dot 类型（中毒/灼烧/流血等）：
  仅决定视觉表现和套装条件判断（如烈焰套"灼烧实例≥3"），
  不影响伤害计算逻辑。

例：毒刃 — 攻击力×80%（直伤）+ 攻击力×30%/次（中毒，持续8秒）
  Lv.50 玩家攻击力 300
  直伤 = 300 × 0.80 = 240（走完整管道）
  目标出手CD = 3.0s → 8秒内行动 2 次（t=3s, 6s）→ Dot = 300 × 0.30 × 2 = 180
  目标出手CD = 1.5s → 8秒内行动 5 次 → Dot = 300 × 0.30 × 5 = 450
  Dot 不走管道，固定值

例：毒刃 + 毒雾 同时作用于同一目标
  毒刃实例：攻击力×30%/次，剩余3秒
  毒雾实例：攻击力×50%/次，剩余2秒
  目标每次行动时 2 个实例各自跳伤害：毒刃 90 + 毒雾 150 = 240/次
  目标行动越快 → 总 Dot 越高
  再放一次毒刃 → 毒刃实例刷新为5秒（模式A，不创建新实例）

极端情况（规则3）：
  ├─ 目标出手CD > Dot持续时间 → 持续时间结束前未行动 → Dot跳 0 次，完全浪费
  │   例：撕裂6秒Dot + 目标出手CD 8s → 6秒内未行动 → 0次Dot，仅吃到直伤
  ├─ 目标出手CD极短（速度封顶50%，CD=1.5s）→ Dot持续5秒 → 可能跳 3~4 次
  ├─ 目标被冻结/眩晕（无法行动）→ Dot 不跳（冻结/眩晕期间不出手 = 不触发）
  │   → 这是控制流对 Dot 流的反制：控住你就跳不了 Dot
  └─ 目标死亡 → Dot 实例立即移除

反向情况（规则2）：
  ├─ Dot 持续期间单位死亡 → 实例立即移除，剩余次数不跳
  ├─ Dot 持续期间 Debuff 被净化（如有净化机制）→ 实例立即移除
  └─ 怪物出手CD固定 → Boss/精英/普通的 Dot 跳数可预期（见怪物案出手CD值）

设计柱检验：
  Dot 每次行动触发 → 满足柱2（Build深度）
  - Dot流天然克制速度流（出手越快→受Dot越多）
  - 控制流反制Dot流（冻结/眩晕期间Dot不跳）
  - 速度/控制/Dot 三者形成克制三角
```

## 9. 战斗胜负条件

### 9.1 胜利

```
条件：敌方全体单位 HP ≤ 0
结果：
  → 立即结束战斗
  → 结算奖励（EXP + 金币 + 装备掉落）
  → 玩家 HP 保持当前值（不回满）
  → 回到地图，继续走圈
```

### 9.2 失败

```
条件：玩家 HP ≤ 0
结果：
  Step 1 — 检查复活币数量
    若有复活币（≥ 1）：
      → 复活币 -1
      → 玩家 HP 回满
      → 回到地图，继续走圈
      → 无其他惩罚
    若无复活币（= 0）：
      → 强制传送回 🏠勇者之家
      → 扣除当前金币 × 15%
      → 复活币回复到 3/3
      → 玩家 HP 回满
      → 回到地图，从勇者之家继续走圈
      → 无 EXP/装备掉落惩罚（仅扣金币）

  Boss 战失败特殊规则：
    → 无复活币时同样强制回勇者之家 + 扣金币
    → 另外触发 Boss 复活/降档（见 [[怪物系统细化案【定案】]] §1.3）
```

> 复活币来源：初始 3 个，上限 3 个。踩 🛌休息格 +1。3枚耗尽后战斗失败 → 强制回勇者之家 + 扣15%金币 + **回复到3枚**。详见 [[角色属性策划案【定案】]] §2.4 和 [[大地图规则细化案【定案】]] §6。

### 9.3 平局（50回合上限兜底）

```
条件：战斗进行了 50 回合仍未分胜负
  （1 回合 = 所有参战单位各行动 1 次）

结果：
  → 按失败处理（无收益 + HP回满）
  → 记录日志：[平局] 玩家Lv{X} vs 怪物Lv{Y}，回合=50

触发场景：多单位精英战中"双方回血 > 伤害"导致无限循环。
          正常战斗约 15~30 回合，50 回合极少触发（是安全兜底）。
```

## 11. 离线收益计算

### 11.1 核心原则

```
离线期间不执行真实战斗模拟，所有战斗均按胜利计算收益。

原因：
  - 真实战斗模拟需要完整的CD队列、技能优先级、判定流程
  - 离线数小时可能积累数百场战斗，逐场模拟计算量过大
  - 收益估算 = 快速计算，保证玩家上线即有收益，不阻塞体验
  - 全按胜利 = 离线收益是纯增量，让玩家"回来就有收获"

上限：离线收益最多计算 12 小时（超过12小时按12小时计）。
仅计算战斗收益，非战斗格离线不触发。
```

### 11.2 收益计算公式

```
Step 1 — 计算离线时长
  离线时长 = min(实际上线时间 - 最后下线时间, 12小时)
  单位：秒
  若 < 1分钟 → 不计算离线收益，直接继续在线走圈

Step 2 — 估算战斗场数
  掷骰次数 = 离线时长 / 掷骰间隔（固定 3 秒）

  各战斗类型触发率（基于标准地图格子分布）：
    普通战斗 ≈ 35%
    精英战斗 ≈ 15%
    挑战    ≈ 5%
    非战斗  ≈ 45%（不产生离线收益）

  普通战斗场数 = 掷骰次数 × 35%
  精英战斗场数 = 掷骰次数 × 15%
  挑战战斗场数 = 掷骰次数 × 5%

Step 3 — 单场收益（全胜，不乘胜率修正）
  怪物等级取玩家当前等级（离线按自身等级匹配）。

  普通战斗（单场）：
    金币 = 怪物等级 × 11.5 × (1 + 金币加成%)
    EXP  = 怪物等级 × 14   × (1 + 经验加成%)
    装备 = 15% 概率掉落 1 件（品质按对应规则，受幸运修正）

  精英战斗（单场）：
    金币 = 怪物等级 × 27.5 × (1 + 金币加成%)
    EXP  = 怪物等级 × 32.5 × (1 + 经验加成%)
    装备 = 必掉 1 件（品质按精英掉落表）

  挑战战斗（3波连战，全胜）：
    金币 = 怪物等级 × 50 × (1 + 金币加成%)
    EXP  = 怪物等级 × 60 × (1 + 经验加成%)
    装备 = 必掉 3 件
    额外 = 玩家等级 × 100 金 + 玩家等级 × 80 EXP（全胜奖励）

Step 4 — 汇总离线收益
  总金币 = Σ(各类型战斗场数 × 单场金币)
  总EXP  = Σ(各类型战斗场数 × 单场EXP)
  总装备 = 按各类型掉落规则随机生成

Step 5 — 上线展示
  弹出离线收益汇总面板：
    "离线 X 小时，获得了以下收益"
    "金币：XXX | EXP：XXX | 装备：Z 件"
```

### 11.3 边界情况（规则3）

```
离线 > 12 小时：
  → 仅计算 12 小时收益，超过部分不累计

离线 < 1 分钟：
  → 不计算离线收益，直接继续在线走圈

离线期间装备背包满：
  → 新装备正常产生，按 [[背包道具货币系统案【定案】]] 规则：
    自动分解最低品质未锁定装备；全部锁定时不掉落，记录日志

玩家在任何类型格子离线：
  → 不触发该格效果，上线后停回该格，立即掷骰继续
  → 若该格是战斗格 → 按胜利结算当次战斗后停回该格

复活币：
  → 离线期间不消耗（没有真实战斗，不涉及失败）
```

### 11.4 设计柱检验

> 离线全胜 → 满足柱1（挂机爽感）+ 柱5（不肝不氪）
> - 离线回来必有收益，不扣任何资源
> - 12小时上限防止离线收益通胀
> - 简单公式，性能开销极低，服务器可快速批处理
