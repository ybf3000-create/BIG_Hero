## 三、美术风格建议（P2阶段确认）

| 风格 | 说明 | 适合度 |
|------|------|--------|
| **像素风** | 16/32px像素，低成本高辨识度 | ★★★★★ 挂机游戏最经典 |
| **扁平卡通风** | 简洁色块+粗描边，扩展性强 | ★★★★☆ |
| **手绘风** | 水彩/铅笔质感，氛围感强 | ★★★☆☆ 成本高 |
| **3D低模风** | Low-poly 3D，立体感 | ★★☆☆☆ 开发成本高 |

> 建议：像素风或扁平卡通风，与挂机游戏的轻量级调性最匹配

## 四、分阶段美术投入计划

| 阶段 | 时间点 | 美术工作 | 产出 |
|------|--------|---------|------|
| Phase 0~1 | 开发初期 | 全部 emoji + CSS色块占位 | 零美术成本，跑逻辑 |
| Phase 2 结束 | 战斗可打 | game-icons.net 批量拉图标(CC0) | 技能/槽位/控制状态图标 |
| Phase 3 结束 | 装备成型 | AI生图出 20 个 Boss 头像 | Boss 辨识度 |
| Phase 4 结束 | 天气天命卡 | 确定美术风格 | 统一视觉方向 |
| Phase 5 | 离线打磨 | 统一换皮+补全所有素材 | 最终交付品质 |

**核心原则：美术永远不阻塞开发进度。先用占位符跑逻辑，美术素材是配置表里的一个字段，后期替换零代码改动。**
